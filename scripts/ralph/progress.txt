## Iteration - Fri Jan 30 2026 21:30 UTC
Story: E2-US-001 - Combat State Serializer
Status: PASSED

### Changes Made
- Created `llm/src/tactician/state_serializer.py` with `serialize_combat_state()` function
- Imports core models and uses `get_current_actor`, `get_available_actions`
- Serializes combatants with hex positions, stats, resources, conditions
- Serializes terrain tiles with properties (dangerous, cover, difficult, etc.) and hazards list
- Computes turn order with side and acted status based on current round
- Enriches actions with parameters: potential targets (enemies within sensor range) with distances, damage predictions for weapon actions (min/max/average damage)
- Added unit tests in `llm/tests/tactician/test_state_serializer.py` covering empty scenario, single combatant, rounds/turns
- Updated PRD.json to mark story as passing

### Learnings
- Core provides `get_current_actor` and `get_available_actions` for current actor detection and action listing
- Hex coordinates serialized via `model_dump(mode="json")` produce q/r/s fields
- Terrain map tiles contain elevation, cover, line-of-sight blocking, dangerous flags
- Weapon damage predictions require resolving weapon definition and computing dice statistics
- Unit tests must be run with PYTHONPATH set to include core module
