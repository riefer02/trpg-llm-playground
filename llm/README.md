# LLM Fine-Tuning Pipeline

Synthetic data generation and fine-tuning pipeline for TTRPG systems.

This directory contains all the LLM-related tooling that was originally at the root of the repository.

## Structure

- `src/` - Core Python modules for data processing, RAG, and training
- `colab/` - Google Colab notebooks for remote execution
- `scripts/` - CLI tools and utilities
- `config/` - YAML configuration files
- `dataset/` - Generated datasets and checkpoints

## Usage

See the original documentation in the colab notebooks and config files.
